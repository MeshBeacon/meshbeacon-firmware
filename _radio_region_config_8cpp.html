void radioregionconfig::begin ()
 Load a previously field-provisioned region from flash, if one exists, and apply it to DuckLoRa::defaultRadioParams.band and DuckLoRa::uplinkChannelPool. Applies the compile-time MY defaults if none was ever provisioned (or storage failed an integrity check). Should be called once, early in setup, before setupLoRaRadio()/setupWithDefaults() initializes the radio.
